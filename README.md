# Gyanith '25 Desktop-Inspired Web Interface

Interactive desktop-style React frontend built for **Gyanith '25** at NIT Puducherry. The interface emulates a desktop operating system environment with interactive icons and application views.

## Repository Structure

| Path | Description |
| :--- | :--- |
| `gyanith25-home/src/Component/Home.jsx` | Main desktop workspace and taskbar layout |
| `gyanith25-home/src/Component/routes.jsx` | Client-side route definitions for desktop views |
| `gyanith25-home/src/Component/Other-folders/` | Application view components (`files.jsx`, `internet-explorer.jsx`, `photo.jsx`, `whatsapp.jsx`) |
| `gyanith25-home/src/Component/Asset/` | Desktop icons and visual assets |

## Getting Started

```bash
cd gyanith25-home
npm install
npm start
```
